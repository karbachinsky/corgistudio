# Corgi Studio

Public pages for the studio's games: the privacy policy and support page each
app needs a live link to.

```
feed-the-corgi/    Feed the Corgi (iOS) — privacy + support, en / ru / he
```

Plain static HTML, no scripts, no analytics, no cookies — which is also what the
policies promise. Each game's pages are generated from templates kept in that
game's own repository (`store/site/`); edit them there and regenerate rather
than editing the files here.

A new game gets its own folder next to this one, with the same two pages.
